# PulseDeck 0.3

Run `Install/PulseDeck-Server.exe` on your 64-bit Windows PC and install the APK from `Install/` on your Android phone. The APK supports 32-bit and 64-bit ARM phones. Keep your existing Windows `config.json` beside the new EXE if you want to keep your settings. Keep both devices on the same private Wi-Fi.

Open the phone app, tap **Pair PC**, and enter the PC address, port and six-character code shown in the Windows window. If the new APK will not install over your previous copy, uninstall the old app first, then install this one and pair again.

The `Source/` folder is only needed if you want to rebuild. To use it with GitHub Desktop, copy the contents of `Source/` into your cloned repository, including `.github`. Do not upload your personal `config.json`. See `Source/README.md` for the full setup and build instructions.
